# 语音理解与直接评分（027）

按你的要求，回答提交后直接评分并生成报告。术语读音不标准、停顿和重复不单独作为扣分理由；模型按实际表达的概念、做法和逻辑评分。转写有疑点时保留提示，回听和纠错均可选，不再卡住分数或总分。

| 项目 | 当前行为 |
|---|---|
| 术语误读、逐词读参数 | 当题热词同时包含worker_prefetch_multiplier与worker prefetch multiplier等读法；模型结合用途和上下文理解，不仅按拼写判断 |
| 不能确定的转写 | 仍给出有效模型分数；保留识别提示和判断置信度，不把疑点额外换算为扣分 |
| 总分与导出 | 所有有效题目按原冻结权重计入总分；页面、JSON和CSV一致 |
| 真实评分失败 | 继续显示处理中或失败并支持重试，不把模型失败伪造成0分 |
| 回听纠错 | 可选择题目播放音频/视频；“按需回听与修正转写”仅用于需要时纠正识别错误，保存后自动重评 |
| 原始证据 | 录音和原文不被术语表改写；历史评分保留，新评分使用新revision；不补造候选人没说出的知识 |

识别置信度未知仍显示未知，不能冒充100%准确。热词只来源于本题冻结技术词，不发送标准答案正文，也不从候选人的回答中提取指令。阿里云支持按请求传入热词；本次在现有配置上补齐自然读法，未更换供应商或夸大词权重。[官方说明](https://help.aliyun.com/zh/model-studio/improve-asr-accuracy)
